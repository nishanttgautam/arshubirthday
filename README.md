# Birthday website for Arshu

- index.html  : the whole website (edit text at the top of the script, inside const C={...})
- images/     : the 9 photos (keep the same file names)
- vercel.json : optional settings

## Deploy on Vercel
1. Go to vercel.com/new and log in.
2. Upload / drag this whole folder. Framework preset: Other. No build command needed.
3. Click Deploy. You get a link like https://your-project.vercel.app

## Alternative: Netlify
Drag this folder onto https://app.netlify.com/drop
